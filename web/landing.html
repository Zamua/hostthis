HOSTTHIS(1) User Commands HOSTTHIS(1)

Name

hostthis - pipe a file in, get a public URL out

Synopsis

cat file | ssh -T hostthis.dev [slug] [-- opts]
tar czf - dir | ssh -T hostthis.dev [slug]
ssh hostthis.dev command [args]

Description

Renders HTML, Markdown, diffs, Mermaid, PDF, CSV, JSON, folded stacks (flame graph), NDJSON logs and plain text at a random subdomain. A gzip-tar is a static site. No signup: your ssh key is your identity, and only it can change what it uploaded. Everything persists until you delete it.

Upload

cat file | ssh -T hostthis.dev
new paste; URL on stdout, QR code on stderr
cat file | ssh -T hostthis.dev slug
new version; same URL
-- --name "label"
set a label
-- --type kind
force the renderer: html, markdown, diff, mermaid, pdf, csv, json, flamegraph, log, text

-T silences ssh's pseudo-terminal warning.

Persistence

Key-value rooms on the page's own origin. The room id is the only key.

POST /api/rooms
new room: {"id": "uuid"}
GET /api/rooms/id
all keys as one JSON object
GET /api/rooms/id/key
one value, raw bytes
PUT /api/rooms/id/key
write; body is the value
DELETE /api/rooms/id/key
remove

Values are bytes; JSON values nest as JSON in whole-room reads. 256 KiB and 256 keys per room, 64 MiB per app.

Websockets

GET /api/rooms/id/ws
a snapshot, then every put and delete
your frames
relayed to other clients, not stored
{"type":"ping"}
every 20 s; answered with pong
close 4001
dropped for a newcomer after 2 min without ping; reconnect

64 sockets per room; frames up to 32 KiB.

Push

GET /api/push/key
VAPID public key
PUT|DELETE .../id/push/subscriptions
add or remove a PushSubscription
PUT .../id/push/schedule
{"tz", "items": [{"id", "at": "HH:MM", "days", "title", "body" | "bodyKey", "url", "tag"}]}
POST .../id/push/test
send now

"when" (RFC 3339) fires once instead of at/days. bodyKey reads a room key at send time. 16 devices and 16 items per room, 8 sends per device per day, one test a minute. push and push/* are reserved keys.

Limits

quota
1 GiB per key, after compression
paste
10 MiB after compression
site
1 GiB unpacked

Exit Status

0  ok              3  no ssh key
1  error           4  not found
2  usage           6  rate limited

Environment

NO_COLOR or TERM=dumb disables color.
